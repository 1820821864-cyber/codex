# 身份与空间质检

## 人物身份

- 原始身份参考优先于已经漂移的成图。编辑时同时声明“编辑目标”和“身份权威参考”。
- 正面参考图不适合直接要求极端侧脸；身份敏感时优先三分之二正脸，使双眼、鼻、嘴和下颌都可比较。
- 强烈表情、广角近摄、过度逆光和重度风格化都会降低相似度。先锁身份，再逐步增加表情与风格。
- 以可见特征描述差异，如脸型、眼睛颜色、鼻长、唇形、下颌、发际与发型；不用“更像一点”作为唯一修复指令。

## 空间拓扑

复杂画面生成前先写区域表：

| 区域 | 应出现 | 不应出现 |
|---|---|---|
| 隔断内侧 | 内侧人物、内侧道具、约束锚点 | 外侧人物躯干 |
| 隔断平面 | 栏杆、门缝、玻璃边界 | 穿过实体材质的肢体 |
| 隔断外侧 | 外侧人物与外侧环境 | 内侧锁链、内侧家具 |

物体跨区必须经过可见开口。写清“手掌、手腕、前臂、手肘”分别位于哪里，不能只写“伸手穿过”。

## 遮挡顺序

对复杂接触建立从摄影机到背景的顺序，例如：前景虚化栏杆 → 外侧人物前臂 → 栏缝 → 内侧手掌与脸 → 内侧墙。每次编辑后检查遮挡顺序是否仍成立。

镜面与倒影必须标明真实人物数量、反射所属对象和反射平面；倒影不得被误读为额外实体人物。

## 手、约束与道具

- 对手部写明左右手、动作、接触点、可见手指数和受力方向。
- 锁链、绳索或牵引物写明起点、路径、终点、松紧和所在区域。若约束限制动作，展示拉直到极限的路径。
- 锁链不得穿越栏杆实体、进入错误区域、悬空或搭在无关人物身上。
- 道具数量、落点和持有者必须唯一；同一物体不能因反打、离画或编辑而复制。
- 场景参考图已有家具时，只复用其原物，不因剧情需要生成同类新家具。

## 出图检查

逐项回答“通过／失败＋证据”：

1. 人物数量和身份是否正确；参考脸是否可辨。
2. 人物形态、伤势、服装和时代是否符合当前剧情。
3. 动作是否存在明确起因、接触、受力与未完成结果。
4. 人物、栏杆、门、镜面和道具位于正确区域。
5. 手指、手腕、前臂、锁链和道具是否有连续路径。
6. 前中后景是否各有职责，光源是否解释空间。
7. 标题是否逐字正确、唯一且未遮挡关键叙事。
8. 禁止项是否真正未出现。

任何关键项失败，不把成图报告为完成；先做最小范围修复。
