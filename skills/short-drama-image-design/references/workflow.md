# 协作与执行工作流

## 输入合同

按任务需要从其他分支读取，而不是重新发明：

- `short-drama-script-analysis`：人物关系、冲突、题材承诺和不可剧透边界。
- `short-drama-story-writing`：当前场景的可见事件、动作因果和情绪转折。
- `short-drama-assets`：人物身份图、时期造型、场景布局、道具数量与确认状态。
- `short-drama-prompts`：镜头时段、人物形态、段尾状态、可见／排除对象和连续性限制。

导演只要求概念探索时，可用最少必要输入直接工作；导演要求忠实还原具体剧情时，必须读取相关上游交付。

## 任务拆解

生成前锁定：

1. 用途：主海报、角色海报、单集封面、剧情关键帧、场景参考或编辑修复。
2. 画幅与文字：比例、唯一文案、排版安全区和禁止出现的文字。
3. 输入图职责：每张图只声明实际用途；人物图默认是身份参考，不自动成为编辑底图。
4. 剧情瞬间：用一个可见事件表达“刚发生什么、正在发生什么、下一秒可能发生什么”。
5. 不可变项：身份、人物数量、形态、伤势、服装、场景、道具和时段。

## 新建与编辑

- 提供图片只用于身份、风格或构图指导时，按“带参考的新建”处理。
- 要求保留现有图的大部分内容并修改局部时，按“编辑”处理；每轮重复写明保持不变的内容。
- 身份已漂移时，不以漂移后的成图作为唯一人物依据；同时提供原始身份参考，并声明原始参考优先。
- 一套宣传图每张独立调用一次图像生成，统一身份、色彩和字体规则，但让每张承担不同传播主题。

## 生成与复核循环

1. 先生成一张完整候选。
2. 按主体、身份、事件、空间、手部、道具、文字和排除项逐项复核。
3. 若失败，指出可观察的穿帮，不用“感觉不对”代替诊断。
4. 单点修复：一次只修改身份、空间、动作、文字或光线中的一个主要问题，并重申其余不可变项。
5. 修复后重新检查；不得因为修正局部而接受新出现的身份漂移、复制道具或文字错误。

## 系列化交付

系列海报先定义共同视觉语法：人物身份、时代、基础色板、字体方向、标题规则和禁止项。再给每张分配唯一主题，如危机守护、身份暴露、政治对抗、日常暗涌、追逐、囚禁或记忆。避免所有图片退化为“双人正面摆拍＋装饰背景”。
