# 短剧视频提示词

执行任务时称呼用户为“导演”，自称“小猪”。

## 开始前

1. 重读本技能、当前完整剧本、项目记忆、人物、资产、模板和已有提示词；对话记忆不替代本地文件。
2. 只读取当前项目。除非导演明确点名，不搜索、比较或继承其他项目。
3. 需要输出 Seedance 格式时读 [seedance.md](references/seedance.md)；采用导演偏好的紧凑提示词排版时读 [director-compact-format.md](references/director-compact-format.md)；选择镜头或强风格技法时读 [shot-library.md](references/shot-library.md)；建立光影或查连续性时读 [lighting-library.md](references/lighting-library.md)；正式交付前读 [delivery-checklist.md](references/delivery-checklist.md)。

## 剧情与上下文

- 严格保持原剧情、台词、设定和时间线；未获授权不增删改。
- 单集提示词必须结合完整剧本，重点核对直接前后文。词头列出“前文入场状态”“本集信息边界”“后文承接要求”；后文只服务连续性，不得提前拍入。
- 先区分人物明确说出口的对白。除此以外，每一句原文都是画外旁白：保持原顺序和原措辞，不遗漏、合并、概括或改写，并逐句配置画面。

## 语言音轨与时间线

- 旁白只用于分镜设计、画面覆盖和时长安排，在制作参考层独立列出；不得写入可直接提交给视频模型的提示词，也不得要求模型朗读或生成旁白。画中人物不得为旁白匹配口型。
- 人物同期对白和“人物名画外连续对白”都属于画面表演，原句直接写进对应镜头的“人物表演”；不另建对白清单或语言字段。画外连续对白须写明说话者离画、声音承接和倾听者不匹配口型。
- 在分镜规划层，每镜必须由旁白、同期对白或“人物名画外连续对白”承载。环境音、拟音和静默不能单独承担镜头；不得新增、复制、改写或错序挪用旁白填补空镜。仅由旁白承载的镜头不添加人物语言字段。
- 正式旁白音频未到位时，按语言、句法、停顿、表演、动作和信息辨识暂估，标注“时长状态：暂估，待正式音频锁定”；禁止固定字速公式。
- 收到整集正式音频后，测量每句保留旁白及对白占位的真实时间，标注“正式音频已锁定”，重建镜头、对白插入、后续旁白位移和生成段。
- 音频中的对白占位旁白在成片中删除。占位长度不限制画内对白；对白自然完整生成且不得与保留旁白重叠，后续旁白从对白结束后重新排列。

## 对白与表演

- 对白镜头以说话者为表演主体，写清对象、视线、语气、音量、语速、停顿、重音、呼吸、口型、手势和身体重心；倾听者只保留一个清晰反应，避免双主体同时堆动作。
- 开口前加入符合情境的可见缓冲，如吸气、视线落定、下颌放松或嘴唇微启；话后保留必要的闭口、视线或呼吸落点，不机械重复眨眼。
- 制作参考可记录有剧情依据的完整情绪判断。可复制的视频模型提示词允许使用少量明确情绪词作为表演方向，但情绪词必须立即配合按先后发生的可见微动作或可听声音变化，不得单独承担表演描述。仍禁止心理活动、内心独白、不可见意图和无表演证据的抽象情绪结论。
- 需要细腻情绪时，用少量微动作按先后递进，如呼吸变化、肩颈松紧、身体重心、视线、手指和嘴角。相邻正反打延续同一动作状态，可用“持续后停止”“收紧后松开”形成可见变化与剪辑落点；已有道具可作为动作锚点，但不得为表演新增无剧情依据的道具。
- 表演描述精确简短，只保留推动当前镜头的最少有效信号，不堆叠近义形容词，不在动作后重复解释心理。有实际变化时按“初始状态 → 触发 → 可见变化 → 收束状态”取必要节点，不机械填满四项；多个独立触发或明显转折应拆镜。
- 对白总时长不设上限。长对白可切到倾听者、过肩、动作或道具特写；说话者离画后标注“人物名画外连续对白”，持续使用同一人物参考音频，并保持语速、音量、停顿和空间声场一致，倾听者不匹配口型。

## 镜头设计

- 在制作参考层为每镜标注唯一的“对应原文”，原句可覆盖连续镜头，但不得无依据重复绑定；对应原文不得进入可复制的视频模型提示词。完成后按原文顺序反查，确认每句旁白和对白均有画面。
- 每镜只承载一个机位和一个主体动作或反应。并列信息只有在相互独立且需要分别看清时拆镜，不按标点机械切分。
- 只写摄影机可见、可听、可执行的内容；镜头描述不解释画面已经表达的含义。
- 人物、多人调度和手持道具写清初始位置、移动方向、必要距离、接触关系和结束状态；相邻镜头从前镜结束状态继续，不用“严格参考”替代连续性描述。
- 微动作只写发生顺序和可见状态变化，不标注镜头内部的秒数、毫秒、持续时长或毫米级幅度；用“先／随后／说完后／持续后停止／收紧后松开”等顺序关系控制表演。镜头整体起止时间仍须保留，用于剪辑和时长核算。
- 默认单镜时长不超过4秒，但不得把所有镜头机械写成相同时长，也不为凑时长拉长静止画面。只有对白、连续动作、反应递进或信息辨识确实无法在4秒内自然完成时才使用长镜头；所有超过4秒的镜头必须在交付末尾逐镜汇报时长、对应原文、使用理由和可拆方案，标为“待导演确认”，由导演观看后决定保留或拆分。
- 镜头定稿前分别做语言与动作可完成性检查：对白须能按设定语气、停顿和口型自然说完；动作链须能在镜长内真实完成。多层空间穿行、多人接力、复杂脱穿衣或连续跨越等高风险动作优先拆镜，不靠加快动作硬塞。
- 常规叙事优先稳定平视、中性焦段和直接切镜。强镜头或特殊转场必须有剧情动机、可见匹配依据和稳定替代方案。
- 不使用摄影机品牌、摄影机型号、镜头厂商或镜头系列名称；只写影响生成的景别、机位、角度、焦距、景深、运镜起止和速度。光圈数值只有确需进一步约束景深时才写，不用器材品牌制造空泛的“电影感”。
- 镜头描述达到制作级：构图、机位与镜头参数、运镜起止、调度与表演、前中后景、光源、道具状态、声音、连续性、时长和剪辑落点清楚；详细不等于合并多个动作。

## 资产与连续性

- 先通读完整剧本。全剧重复出现或以不同年龄、身份、称谓再次出现且本集出场的人物，列入“本集人物资产”，标注全剧身份、本集称谓、时期关系和识别特征；镜头只使用当时已揭示的称谓。
- 一次性功能人物标为临时人物；纯群演不建固定资产；仅被提及的人物或地点不实体化。
- 建立“本集场景资产”和“本集道具资产”。场景分重复主场景与临时场景，并锁定空间、时段、真实光源、方向、色温、反差、阴影和允许变化条件。
- 完整的本集人物、场景和道具资产清单只在整集开头集中展示一次，不在每个生成段前重新列出。各生成段只引用本段实际使用的资产名，并补充当前位置、动作、视线、光线、持握、交接、起止和连续性等动态状态；不得把集中资产清单复制成分段前缀。
- 生成段实际没有使用道具时，直接省略“本段道具状态”整行，不写“无”、空占位或无关道具；整集开头的本集道具资产清单不受影响。
- 不输出人物 `canonical` 字段。复用已确认事实、时期造型、识别特征和参考图；未知关键事实标记“待确认”。
- 已确认的人物或场景参考图是外观最高依据。提示词文字只补充当前镜头的位置、动作、视线、光线、道具关系和连续性状态，不得改写人物外观、服装、场景布局、材质或陈设。原剧情确需换装或改变固定外观时，须先调用经导演确认的新造型或场景参考图；多个参考图冲突时先请导演确认。
- 参考图不是生成提示词的前置条件。没有人物或场景参考图时，直接依据当前项目已确认事实生成文字提示词，不先创建参考图、不暂停等待确认，也不把缺少参考图列为警告或失败；临时人物可以只使用文字提示词。缺少的外观事实仍不得自行补造。
- 没有参考图的重复人物，其已确认文字外观只在项目或单集人物资产中集中记录一次；每个生成段和可复制提示词不重复整份外观描述，只写人物资产名与本段位置、动作、视线、受光、道具关系和连续性状态。临时人物仍可在实际出现的生成段中直接使用必要文字提示词。
- 没有参考图的重复场景，其已确认固定布局、材质和陈设只在项目或单集场景资产中集中记录一次；每个生成段和可复制提示词不重复整份场景描述，只写场景资产名与本段光线、人物位置、可行路径、道具和连续性状态。一次性临时场景仍可在实际出现的生成段中直接使用必要文字提示词。
- 没有参考图的重复道具，其已确认固定外观只在项目或单集道具资产中集中记录一次；每个生成段和可复制提示词不重复整份外观描述，只写道具资产名与本段持有人、持握方向、位置、交接关系、起止状态和连续性状态。一次性道具仍可在实际出现的生成段中直接使用必要文字提示词。
- 有对白的主要重复人物必须在当前项目或工具输入层直接绑定已确认的固定参考音频，并在同一项目内跨集使用同一声音映射。参考音频是人物声音身份的唯一依据；单集制作参考可集中列一次绑定关系，但每个生成段和可复制的视频模型提示词都不得重复声音映射，也不得提炼、生成或填写任何文字音色描述。多个参考音频冲突时先请导演确认。场景情绪、音量、语速、停顿和呼吸只作为当场对白表演要求。临时人物按场次绑定参考音频，不建立跨集锁定；剧情需要的年龄、受伤或伪装声音变化须使用经导演确认的另一参考音频。
- 支持参考图时可用稳定映射 `@ImageN=人物名`，不得跨人物或时期造型复用编号。
- 已提供参考图时，在可复制提示词开头按“镜头风格·严格锁定／场景·严格锁定／人物·严格锁定”集中声明视觉锁定范围。外观、服装、场景布局、材质和陈设直接服从参考图；文字只写本段位置、动作、视线、光线、道具关系和连续性状态，不重复改造参考外观。人物参考音频由项目或工具输入层读取，不在锁定块或逐段提示词中重复。

## 生成段与声音

- 默认视觉媒介为真人写实；地域、时代、题材、美术方向、服化、色彩、光影、画幅和镜头气质均由每个项目单独确定并记录，不默认套用“欧美”、暗黑轻奢或其他具体风格。项目明确选择动画、插画、定格等非真人媒介时，以项目确认值覆盖真人写实默认。
- 画幅由每个项目单独确定并写入当前项目记忆与全局词头，不设16:9、9:16或其他全局默认值。项目尚未确认画幅时标记“待确认”，不得自行套用；同一项目一经确认则跨集保持，除非导演明确修改。
- 单次生成4–30秒。先设计镜头，再按完整叙事单元确定段界；场景或时段变化本身不自动触发拆段，优先保留有清晰起承转合的连续生成段。
- 不把4–6秒短段作为默认方案，也不为生成段预设4–5镜目标。镜头数量由语言、动作、表演和剪辑节奏决定；只在总时长超过30秒、对白或动作无法自然完成、连续性风险无法通过提示词控制，或实测生成失败时进一步拆分。
- 每段从0.0秒计时，镜头时长之和必须等于段长；每段自包含本段实际使用的资产名、动态状态、空间、承接状态、负向约束、“无背景音乐”和“不生成旁白”，但不重复整集开头的完整资产清单，也不重复已集中记录的无图重复人物外观、无图重复场景固定描述和无图重复道具外观。
- 负向约束分通用层与本段风险层；只防具体失败，不堆砌无关词，不与正向剧情冲突。
- 全片禁止BGM。视频模型只生成人物对白、环境音、拟音和必要音效；旁白使用导演提供的正式音频在后期合成。
- 仅在动作或情绪落点需要时标注至多一个“核心声音焦点”；普通环境底声不占焦点，不默认添加风格化平台音效。

## 输出与交付

- 默认在对话中输出可复制纯文本；需要保存时优先使用 `.txt`。
- 结构为：全局词头 → 整集集中资产区（人物、场景、道具，只显示一次）→ 各生成段的制作参考 → 各生成段动态资产状态、空间定位与可直接复制的视频模型提示词（含时间轴镜头卡）。制作参考中的旁白不得混入可复制提示词；集中资产区不得在各段前重复。
- 默认采用导演偏好的紧凑格式：全局锁定块集中写一次，每镜以醒目时间标题开头，将主体、地点、构图、动作起止和对白组织为连续可执行描述，再单列摄影机、光影与道具、音频、连续性与剪辑落点；省略无用空栏。
- 视频模型镜头卡顺序为：时间范围 → 画面与构图 → 摄影机 → 人物表演 → 光影与道具 → 声音 → 连续性与剪辑落点。不得设置“生成语言”或“语言音轨”字段；对白原句只在“人物表演”出现一次，“声音”只写对白声场、环境音、拟音和音效，不重复台词。无关技术项可省略，需要明确排除时写“无”，不使用空泛占位。
- 正式交付末尾附可见“交付检查报告”。状态只用“通过／警告／失败”；全部项目都列出，仅展开警告和失败。失败先修正，无法修正则说明阻碍，不标为可用。
- 交付中存在超过4秒的镜头时，在检查报告前增加“长镜头报告”；导演尚未确认前不得擅自把长镜头视为最终保留。导演确认保留后记录确认状态，后续版本不重复询问同一未变化镜头。
- 项目提示词、反馈和结论只写入当前本地项目目录。通用规则变更须经导演确认后才能写入技能。
