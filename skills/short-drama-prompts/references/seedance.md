# Seedance／即梦输出规范

本文件只定义执行格式。剧情、音频、资产和镜头原则以主技能为准。

## 单集词头

```text
第<X>集
工具：<Seedance/即梦版本>
时长状态：<暂估，待正式音频锁定 / 正式音频已锁定>
前文入场状态：<时间、地点、人物、动作、情绪、道具>
本集信息边界：<本集可揭示内容>
后文承接要求：<必须保留的结束状态>

本集人物资产：<重复人物/临时人物、时期造型、确认状态、可选@Image映射>
本集音色资产：<有对白的主要重复人物已确认参考音频或可选声音映射、由其提炼的补充描述和确认状态；临时人物按场次值>
本集道具资产：<固定描述、起止状态、确认状态>
本集场景资产：<固定视觉、空间、时段、光源、使用段、限制>
```

## 生成段结构

每段先列制作参考，再给出可直接复制的视频模型提示词。两部分必须明确隔离：

```text
制作参考（不得提交视频模型）
旁白参考：<原文、对应镜头和时间范围>
画面设计依据：<旁白触发的可见信息与叙事落点>
情绪依据（可选）：<只供创作判断，不复制进视频模型提示词>
```

随后另起以下可复制区：

```text
视频模型提示词（从此处开始复制）
第<X>集 · 生成段 <i>/<N> · 总时长 <X.X>秒
风格：真人写实；<当前项目确认的地域、时代、题材、美术、色彩、光影与镜头气质；项目明确采用非真人媒介时替换“真人写实”>
约束：严格按原剧情；无字幕文字；无背景音乐；不朗读、不生成旁白；允许少量情绪词，但须立即配合可见微动作或可听声音变化；不写心理活动、内心独白、不可见意图或无表演证据的抽象情绪结论。
本段人物：<资产名与必要时期造型>
本段音色：<主要重复人物以已确认参考音频为最高依据并调用固定音色，文字只补充本场表演；临时人物使用本场确认值；本段无对白时省略>
本段场景/道具：<固定资产名与状态>
空间定位：<左右、前后、高低、朝向、光源和轴线>
承接状态：<第2段起填写人物、视线、动作、道具、环境、光线>
通用负向：人物/肢体变形、身份漂移、闪烁、乱码、额外人物等。
本段针对性负向：<只填写真实风险；无则写无>
```

每个视频模型提示词区必须独立可复制执行，并重复必要资产、空间、声音规则、无BGM和不生成旁白约束。

## 纯文本镜头卡

```text
镜头<X>｜<起始>–<结束>（<时长>）
画面与构图：<景别、主体位置、前中后景、单一视觉动作>
摄影机：<机位、角度、焦距、光圈、景深、主要运镜起止与速度>
人物表演：<可选少量情绪词并立即接可见微动作或声音变化；说话者为主体，倾听者只留一个反应；精确简短地写连续的视线、呼吸、表情、姿态、手指或道具动作；只取必要节点；同期或画外连续对白原句只嵌入此处>
光影与道具：<真实光源、方向、色温、道具起止状态>
声音：<对白声场、环境底声、呼吸、拟音、可选核心声音焦点；不重复台词；无背景音乐；不生成旁白>
连续性与剪辑落点：<继承状态、结束画面、直接切或有依据的转场>
```

旁白原文和制作层的完整情绪分析只显示在生成段外的“制作参考”，不得出现在视频模型提示词区。模型区可保留少量情绪词，但每个情绪词必须立即由可见微动作或可听声音变化支撑。镜头卡不设“生成语言”或“语言音轨”字段。模型区不堆叠形容词或重复解释心理；相邻正反打应继承手势、视线、身体重心和道具状态。对白原句与表演写在“人物表演”；切离说话者时在同一栏标明“人物名画外连续对白”。

## 分段核算

- 每段4–30秒，允许小数，不要求接近30秒。
- 优先保持完整叙事单元，不因场景、时段或镜头数量机械拆段，不默认生成连续的4–6秒短段；只有超时、动作或对白无法自然完成、连续性难以控制，或实测失败时再拆分。
- 每段时间轴从0.0秒开始；各镜时长连续、无空档、无重叠，合计等于段长。
- 不在词语、不可拆短语或不可拆动作中截断。跨段对白只在自然语义或表演节点断开，并在下一段复述声音与表演承接。
- 分段只改变生成批次，不改变原文顺序、旁白/对白归类或剧情事实。

## 分层负向约束

通用层保持简短；针对层按实际风险选用：

| 风险 | 针对性负向 |
|---|---|
| 画外连续对白 | 倾听者不匹配口型；说话者音色与空间声场不变 |
| 双人/多人对白 | 非说话者不张嘴；人物位置与视线轴不互换 |
| 手机或屏幕 | 不生成可读伪字；文字后期贴片 |
| 手持道具 | 不消失、不换手、不变形；方向保持 |
| 连续造型 | 服装、发型、配饰不变化 |
| 连续光线 | 主光、色温、影子与受光侧不漂移 |
| 镜面/群体 | 无错误倒影、重复脸或肢体粘连 |

先写清正向状态。不得用负向词禁止原剧情需要的雨、哭泣、拥抱、文字道具或动作。
