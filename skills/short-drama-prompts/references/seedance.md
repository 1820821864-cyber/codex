# Seedance 提示词参考

```text
风格：<写实/动漫/其他>，<质感与光影>。
约束：严格按原剧情；无字幕文字；无背景音乐，仅旁白、人物对白、环境音、拟音和必要音效。
通用负向：变形、多指、面部崩坏、文字乱码、闪烁、抽帧、额外肢体、角色漂移、额外人物。
本段针对性负向：<仅填写本生成段真实存在的风险>。
人物：<姓名>，<已确认的固定外观信息或参考图编号>。
场景：<资产名>，<固定描述词>。
定位：<左右/前后/高低/朝向/光源/机位高度>。

0.0–3.0s <景别与机位>，<焦距> f/<光圈>，<动作与微表情>，<运镜>，<光线>。音频：<环境音/音效/台词>。
```

- 24–35mm：空间与冲击；50mm：常规叙事；85–135mm：情绪特写；100mm 微距：细节。
- f/1.8–2.0：浅景深特写；f/2.8：叙事主力；f/4 以上：环境交代。
- 定位至少写平面方位和垂直关系；复杂站位可用 ASCII 图或参考图锁位。
- 本工作流按用户确认的模型限制执行：每个生成段必须为4–30秒；除非用户明确修改，不再沿用其他旧时长参数。
- 原文中除人物对白外的每一句都是画外旁白：逐句保留原顺序与措辞，并逐句绑定画面，不遗漏、不合并、不概括。画外旁白单列在镜头之前或音轨栏，不写入画面描述；画中人物不为旁白开口或匹配口型。
- 每个镜头必须由语言音轨承载：有同期对白时使用同期对白；说话者切出画面但对白连续时使用“人物名画外连续对白”；两者均无时，必须绑定对应原文旁白。禁止只有环境音、拟音或静默的空镜。环境音与拟音只能辅助，不能代替语言音轨；不得为填补镜头而新增、复制、改写或错序挪用旁白，应调整拆镜、合镜或时长。
- 时长分为“暂估”和“正式音频已锁定”。音频到位前，按实际语言、句法、标点、表演、动作和信息辨识暂估，不使用固定字数除以固定语速的公式；词头必须标明暂估。音频到位后，测量每句保留旁白与对白占位区间的真实起止时间，重建镜头、对白插入、后续旁白位移和生成段时长，并在词头标明正式音频已锁定。
- 整集正式旁白音频含可删除的对白占位旁白时，删除占位音频并由画内人物对白替换。占位长度不约束对白；对白不得与正式旁白重叠，实际对白结束时间发生变化时，后续正式旁白随之重排。
- 同期对白是画内表演，写进对应镜头的动作与表演描述中，注明说话者、对象、视线、开口前后变化、语气、音量、语速、停顿、重音、呼吸、嘴部动作、眉眼、手势、身体重心及对方即时反应。开口前加入符合情境的自然缓冲动作，不机械重复眨眼。情绪必须有剧本依据；长对白或情绪转折按表演节点拆镜。
- 对白与反应按“初始状态 → 台词/动作/信息触发 → 可见变化 → 收束状态”编排。使用“先、随即、逐渐、停顿后、说到某词时、说完时”等时间节点绑定表演变化，不只写静态情绪词。禁止无剧情依据地套用流泪、瞪眼、握拳、颤抖等模板；出现多个独立触发或明显转折时拆镜。
- 对白总时长不设上限。长对白在语义、停顿、情绪或动作节点切换到倾听者、过肩、说话者动作/道具特写或相关表达画面；说话者离画后标注“人物名画外连续对白”，声音保持连续，倾听者不匹配口型。若对白超过单段30秒，只在自然语义停顿处跨段，并复述声音与表演承接。
- 并列人物、地点、物品或动作只有在属于独立且必须分别辨识的视觉信息时才拆镜；标点本身不是强制切镜依据。
- 画面描述只写可见、可听、可执行内容。把心理、比喻和交流意图转译成表情、呼吸、视线、姿态、动作和声音表现。
- 支持参考图的工具可在人物资产中添加 `@ImageN=人物名` 映射，并在镜头中复用；同一编号不得跨人物或跨时期造型混用。不支持时省略。
- 单镜只表达一个视觉动作。瞬时动作或反应通常约1–2.5秒，常规叙事动作通常约2–4秒，复杂动作或环境建立按真实展开时间处理。长旁白可跨多个长短不一的镜头连续播放；不要为了完整播完一句而延长静止镜头，也不要机械套用4秒镜头。
- 相邻镜头默认直接切。只有动作轨迹、前景遮挡、形状/色彩、运动方向或空间关系能够真实匹配时，才使用动作匹配、遮挡、相似物或方向匹配转场，并写清前镜落点、物理衔接方式和后镜进入状态。不得逐镜套用转场标签，也不默认使用旋转、缩放、甩镜或强动态模糊；无充分依据时直接切镜最稳定。
- 所有提示词的全局约束必须写明“无背景音乐”。禁止配乐、音乐铺底、主题音乐、节奏轨和情绪音乐；声音设计仅使用旁白、同期对白、环境音、拟音与必要音效。
- 单镜可同时保留必要的对白、呼吸、环境底声和拟音；仅在剧情动作或情绪落点需要时，标注至多一个“核心声音焦点”。普通持续环境底声不占用该焦点，无明确声学落点的镜头不强行配置。核心声音优先使用画内可追溯的真实声源，不默认添加夸张转场声、提示声、冲击声等风格化平台音效。

## 分层负向约束

每个生成段都写两层负向：

- 通用层：只保留普遍生成故障，如人物/肢体变形、面部或身份漂移、闪烁抽帧、无关文字乱码、额外人物。
- 针对层：只选择本段存在的具体风险。没有额外风险时写“无”，不为了填字段堆词。

常见风险映射：

| 本段内容 | 针对性负向示例 |
|---|---|
| 说话者切出画面 | 倾听者不匹配口型；画外对白音色与空间声场不变 |
| 双人或多人对白 | 非说话者不张嘴；人物位置与视线轴不互换 |
| 手机、电脑、帖子 | 屏幕不生成可读伪字；无乱码字幕；文字后期贴片 |
| 手持关键道具 | 道具不消失、不换手、不变形；握持方向保持 |
| 连续服装或造型 | 服装颜色、款式、发型和配饰不变化 |
| 连续光线 | 主光方向、色温、影子方向和人物受光侧不漂移 |
| 镜面或玻璃 | 不出现额外人物、重复脸或错误倒影 |
| 群体场景 | 不复制主要角色脸；人物肢体不粘连 |

负向约束必须服从正向剧情：原文需要雨、拥抱、哭泣、文字道具或特定动作时，不得笼统写“无雨”“无拥抱”“无哭泣”“无文字”或“无动作”。应先准确写正向状态，再只排除错误形式，例如“屏幕内容留作后期贴片，不生成伪字”。

## 专业镜头字段

选择强风格镜头前先读取 [shot-library.md](shot-library.md)，写明叙事目的并遵守其稳定性与替代方案。常规场景默认使用稳定平视机位和中性镜头，不为展示术语而使用强镜头。

建立场景资产或设计光影时读取 [lighting-library.md](lighting-library.md)。每个场景先锁定真实光源、方向、色温、反差、阴影、曝光和基础色彩；同一连续场景只有发生可见的时间、天气、灯具、门窗、屏幕或位置变化时才能改变光线。

每镜使用以下纯文本顺序：

```text
镜头<X>｜<起始时间>–<结束时间>（<时长>）
语言音轨：<画外旁白原文 / 人物同期对白，台词见人物表演 / 人物名画外连续对白，台词见人物表演>
画面与构图：<景别、主体位置、前中后景、可见动作>
摄影机：<机位高度、角度、焦距、光圈、景深、主要运镜起止与速度>
人物表演：<初始状态、触发、可见变化、收束；人物对白原句嵌入此处>
光影与道具：<真实光源、方向、色温、道具起止状态>
声音：<环境底声、呼吸、拟音；需要时至多一个核心声音焦点；无背景音乐>
连续性与剪辑落点：<继承状态、结束画面、直接切或有依据的转场>
```

旁白原文只在“语言音轨”中独立显示，不嵌入画面。对白不另建镜头外台词栏；其原句与说话表演或画外连续对白状态一起写入“人物表演”。需要明确排除时写“无”，与本镜无关的技术项可省略，不用空泛形容词填满字段。

每镜按实际需要自然组织以下信息，不写空泛形容词：

- 景别与构图：主体在画面的位置、视线空间、画面重心。
- 摄影机：机位高度、俯仰角、焦距、光圈、景深、起止位置、运镜方向与速度。
- 调度与表演：人物走位、身体重心、视线、手部动作、呼吸与微表情。
- 空间与光线：前中后景、人物间距、主光/辅光/实景光方向、色温、反差与阴影。
- 环境与道具：背景动态、天气、材质、道具在镜头开始与结束时的状态。
- 声音：对应旁白、同期对白、环境底声、拟音；确有需要时标注至多一个核心声音焦点。
- 连续性与剪辑：承接上一镜的动作状态、镜头结束画面和明确剪辑落点；若不用直接切镜，补充真实匹配依据和下一镜进入状态。

字段详细度服从单一视觉动作纪律；一旦机位、主体动作组或反应对象改变，就拆成新镜头。

## 4–30秒分段生成协议

先按动作、表演、语言语速和剪辑节奏设计镜头并核算整集实际总时长，再拆成 `N` 个生成段。每段采用以下标识：

```text
第<X>集 · 生成段 <i>/<N> · 总时长 <XX>秒
```

- 每段必须在4–30秒之间，且内部镜头时长之和严格等于该段总时长，不得出现空档或重叠。
- 段时长允许使用非整数秒，也无需接近30秒。镜头时长由内容决定，生成段边界服从镜头，不得先定整齐的段长再反向平均分配镜头。
- 每段时间轴从 `0.0s` 重新计时，不延续上一段的秒数。
- 优先在场景变化、完整动作结束、人物视线落定、对白自然语义停顿或其他自然剪辑点分段；禁止在词语、不可拆短语、不可拆动作中间或关键反应尚未完成时截断。
- 不得通过延长静止画面、机械重复4秒镜头、降低正常剪辑密度或合并视觉动作来凑满段长或减少生成段数量。
- 每段都重复风格、剧情约束、负向提示、必要人物与场景资产、空间定位、音频规则及“无背景音乐”，保证单独复制也能执行。
- 第2段起在镜头前明确写出承接状态：人物位置、身体姿态、视线方向、手中道具、服装状态、环境动态、光线方向与色温，以及上一段的剪辑落点。
- 分段只改变生成批次，不改变原文顺序、旁白/对白归类、剧情事实或镜头连续性。

## 交付检查报告

每次正式交付单集提示词时，在正文末尾附上可见报告。状态只能使用：

- 通过：满足要求，只需一句话说明结果。
- 警告：仍可执行，但存在需要导演知悉的风险；写明原因、影响和建议。
- 失败：不满足硬性要求；原则上先修正再交付。若无法修正，明确阻碍，不得标注成品可用。

所有检查项均须列出，只有警告和失败项展开。推荐模板：

```text
交付检查报告
1. 原文完整性：通过
2. 前后文连续性与信息边界：通过
3. 旁白逐句画面覆盖：通过
4. 每镜语言音轨覆盖：通过
5. 纯文本镜头卡顺序与字段有效性：通过
6. 对白与反应表演节拍、剧情依据及自然开口缓冲：通过
7. 时长状态（暂估/正式音频已锁定）：通过
8. 音频时间线与对白避让：通过
9. 生成段时长及镜头时长合计：通过
10. 人物资产与参考图编号：通过
11. 场景与道具资产：通过
12. 画面可执行性：通过
13. 视觉与动作连续性：通过
14. 场景光源依据、光影动机及跨镜连续性：通过
15. 镜头语言的剧情动机与模型稳定性：通过
16. 转场依据与生成稳定性：通过
17. 分层负向约束的相关性与正负一致性：通过
18. 声音分类、按需核心声音焦点及无BGM：通过
19. 后文信息防泄露：通过
结论：可交付
```

若尚未收到正式旁白音频，第7项必须写为“警告：暂估”，并说明正式音频到位后需重建时间线；不得填写“通过”或声称已锁时。
