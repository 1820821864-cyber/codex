# AI短剧镜头库

本库用于查询镜头用途、生成稳定性和替代方案。具体剧情纪律见主技能。

## 稳定性

- 稳定性分级：高＝通常适合直接生成；中＝需简化背景、人数和动作；低＝优先拆镜或后期完成，并准备稳定替代方案。
- 组合两种以上主要运镜或明显速度变化时拆成连续镜头；人物脸、口型和关键道具优先于运镜。

## 景别与视角

| 镜头 | 主要用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 大全景 ELS | 定场、地理关系、人物与大环境比例 | 高 | 人物表演不承担精细口型 |
| 全景 WS | 全身动作、人物与场景位置 | 高 | 明确人物左右、前后和行动方向 |
| 中景 MS | 常规叙事、动作与表情兼顾 | 高 | 默认叙事主力 |
| 中近景 MCU | 日常对白、轻微情绪变化 | 高 | 保留视线空间与对话对象方向 |
| 特写 CU | 关键台词、反应、信息落点 | 高 | 一镜只突出一个表情变化或物件 |
| 大特写 ECU / 微距 | 眼睛、嘴唇、指尖、关键道具细节 | 中 | 避免复杂动作；必须有剧情依据 |
| 主观视角 POV | 角色所见、信息揭示、短时沉浸 | 中 | 写清视线来源，避免无依据晃动 |
| 过肩 OTS | 对话关系、倾听反应、权力距离 | 高 | 锁定肩位、视线轴和口型归属 |

## 机位与角度

| 镜头 | 可服务的剧情动机 | 稳定性 | 稳定替代 |
|---|---|---:|---|
| 平视 | 客观、平等、自然交流 | 高 | 默认使用 |
| 轻微低角度 | 权力上升、压迫或高光 | 高 | 中近景轻仰，不必极端 |
| 极低仰拍 / 虫蚁视角 | 明确的极端压迫、脚步冲击 | 中 | 贴地局部特写 |
| 轻微高角度 | 脆弱、受困、空间劣势 | 高 | 中景轻俯 |
| 垂直俯拍 / 顶视 | 阵列、路径、困局或地面动作关系 | 中 | 高位斜俯全景 |
| 荷兰角 | 剧情明确的失衡、眩晕或失控 | 中 | 小角度倾斜；不用作普通紧张装饰 |

## 焦点与景深

| 技法 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 浅景深 | 对白特写、隔离杂乱背景、关键物件 | 高 | 明确焦点主体，避免多人同时表演 |
| 大景深 | 空间关系、多层人物信息 | 高 | 控制主体数量，写清前中后景 |
| 焦点转移 Rack Focus | 前后景线索揭示、注意力转移 | 中 | 只做一次焦点转移，主体位置固定 |
| 柔焦 | 有原文依据的回忆、梦境或柔和质感 | 中 | 不用于普通美化，不损失人物识别 |

## 基础运镜

| 运镜 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 固定机位 | 对白、克制情绪、清晰动作 | 高 | 强表演场景优先 |
| 缓慢推进 | 信息或情绪逐渐收紧 | 高 | 写清起止景别与速度，只推进一次 |
| 缓慢后撤 | 关系疏离、揭示环境或结束段落 | 高 | 后景信息应真实存在 |
| 平移/摇摄 | 跟随单一方向动作或揭示相邻信息 | 高 | 单方向、单速度，不来回扫 |
| 轻微手持 | 纪实、奔跑或受控的不安 | 中 | 幅度轻，不用于对白口型特写 |

## 速度变化与甩镜

| 运镜 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 单次慢动作 | 原文支持的撞击、泪滴、关键手势 | 中 | 只强调一个瞬间，不拖长对白 |
| 快到慢跟拍 | 动作峰值或落地瞬间 | 低 | 优先在后期做速度曲线 |
| 俯冲慢变速 | 高速接近后的轻落或聚焦 | 低 | 拆镜并用动作匹配替代 |
| 快—慢—快 Speed Ramp | 动作高潮的节奏变化 | 低 | 后期优先，生成时保持动作连续 |
| 甩镜 Whip Pan | 单镜内部的突发方向切换、喜剧或追逐动作 | 中 | 明确单一甩动方向和落点；不得用于遮盖切镜或制造非硬切过渡 |

## 大型仪式、等级展示与特效递进

仅在原剧情存在仪式、测试、觉醒、召唤、能力等级或同类特效递进时使用；不把奇幻、科幻或大场面风格套入普通现实项目。

### 空间阵列锁定

- 在首镜前集中记录中心物、环绕物、前后左右、高低层级、入口、观礼区以及关键人物的初始位置和朝向；数量、名称与方位必须一一对应。
- 先用稳定全景或高位斜俯建立阵列，再进入局部镜头。后续只改变剧情明确启动、移动或损坏的对象，其余对象保持原方位、距离和高度。
- 每镜写清当前主体相对中心物及相邻锚点的位置；超广角俯冲、环绕和细节展示不得在同一短镜中同时承担。

### 抽象等级视觉化

- 等级、价值或能量强弱使用项目确认的稳定映射表达。颜色不能成为唯一依据；同时选择亮度、作用范围、形体尺度、运动速度、环境影响或群体反应中的必要维度形成可观察差异。
- 同一等级复用同一组视觉规则，不因换镜随意改变；相邻等级只增加剧情支持的差异，保留共同测量锚点，确保观众能直接比较。
- 不写“数百万／数亿粒子”等不可验证数量，也不依赖“顶级、史诗、震撼”等抽象词；改写为稀疏或高密度、覆盖范围、运动路径、照明范围和具体物理反馈。

### 特效变化链

- 按“初始静止状态 → 明确触发源 → 能量传播或汇聚路径 → 可见形态或结果 → 对人物／道具／环境的物理影响 → 衰减后的结束状态”设计；只保留原剧情需要的节点。
- 一个短镜只突出链条中的一个主要状态变化。多个节点无法在镜长内自然完成时，在发光稳定、形态完成、冲击到达或开始消散等清楚落点硬切拆镜，不用加速塞入。
- 光与能量写清来源、方向、作用对象和结束位置；衣料、头发、尘土、阴影或地面反馈每镜只选最能证明力量的必要反应，避免所有反馈同时爆发。

### 同类事件递进对比

- 连续展示同类测试或仪式时，保留相近构图、中心物尺度和观察角度作为比较基准，再按原剧情逐级改变能量、形态、空间影响和人物反应。
- 群体反应按等级分层：背景群体保持统一且克制，只有剧情指定的关键人物获得清晰反应；每一级只增加一个主要反应变化，避免全员同时夸张表演。
- 同一句旁白可以连续覆盖多个对比镜头，但制作参考只标明一次音频及覆盖范围，不得为每个镜头重复播放或改写旁白。

## 硬切落点库

所有镜头、生成段及片头片尾的画面统一硬切。禁止淡入、淡出、叠化、溶解、渐隐、渐显、遮挡、缩放、甩动、旋转等过渡式切镜。硬切只约束画面；有连续性依据的对白、呼吸、拟音或必要声音可以跨硬切延续，但须写明来源、离画状态和承接范围。下表只用于选择自然的硬切时机，不改变硬切方式：

| 硬切落点 | 匹配依据 | 稳定性 | 限制 |
|---|---|---:|---|
| 动作落点 | 相邻镜头承接同一动作阶段 | 高 | 在动作清晰节点硬切，不使用过渡效果 |
| 视线落点 | 前镜视线指向与后镜被看对象一致 | 高 | 遵守视线轴，后镜主体位置明确 |
| 方向落点 | 人物或物体保持运动方向 | 高 | 遵守轴线和空间逻辑 |
| 声音落点 | 对白、呼吸或拟音在切点前后连续 | 高 | 写明声音来源、离画状态和承接范围；只延续声音，不叠加画面过渡 |
| 构图落点 | 两镜主体位置或形状关系清晰 | 中 | 仅帮助硬切可读性，不制造象征物或变形匹配 |
