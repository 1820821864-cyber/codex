# 输出与格式模块

本模块是正式提示词结构、字段、省略规则和负向约束的唯一规则源。正式单集默认套用 `templates/director-compact.md`；工具差异由适配器覆盖字段，不得改写剧情规则。

## OUT-01 交付媒介与层级

- 默认在对话中输出可复制纯文本；需要保存时优先使用 `.txt`。
- 正式整集提示词属于长篇交付时，默认保存为当前项目目录中的独立 `.txt` 文档，并在对话中提供文件链接与简短核验摘要；导演明确要求全文贴入对话时才同时展示全文。项目事实和交付文档不得写入技能仓库。
- 整集结构固定为：精简执行与依据清单 → 各生成段制作参考 → 每段完整统一词头与视频模型复制层 → 长镜头报告（存在时）→ 交付检查报告。
- 正式稿区分两层：制作参考层保留累计时间、原文映射、动态资产状态、空间与承接、入画／排除范围和段尾快照；视频模型复制层使用完整统一词头、单一“本段执行约束”和逐镜提示。制作核算信息不得误混入复制层，复制层也不得以精简为由丢失可执行状态。
- 每段词头是可整体复制的连续区块，固定按“地域与类型及摄影风格 → 项目场景总体状态与美术限制 → 声音与文字边界 → 人物参考 → 道具参考 → 场景参考 → 场景流程”排列，不拆成多个并列锁定标题。
- 正式稿不得为缩短聊天长度、方便概览或减少重复而删除词头、资产状态、空间与承接、逐镜入画范围、风险触发后的排除范围、段尾落幅与承接或完整检查报告。需要精简时另行输出并明确标注“简化预览”，不得把它命名为正式稿、完整稿、审阅稿或可投产稿。
- 制作参考与可复制提示词明确隔离。旁白、对应原文和完整情绪分析只出现在制作参考；不得混入视频模型提示词。
- 默认4秒镜长上限、全片硬切和由工具参数面板控制的画幅属于内部制作约束，不写入每段词头或逐镜描述；仍须实际执行，并在交付检查中核对。只有导演明确要求模型读取其中某项时才写入可复制提示词。

## OUT-02 统一词头与资产筛选

- 每个生成段分别建立一个 `【第<X>集统一词头·严格锁定】` 连续区块，使该段能脱离其他段独立复制提交。固定顺序完整保留，但资产只覆盖本段实际内容，不复制整集资产清单。资产取舍遵循 [assets-references.md](assets-references.md) 的 AST-03／AST-04。
- 已绑定固定人物写为 `<人物名称>：形象参考：@imageN，面部参考：@imageN，声音参考：@音频N；`；已绑定场景写为 `<场景名称>：场景参考：@imageN；`；已绑定道具写为 `<道具名称>：道具参考：@imageN；`。引用后不追加固定外观描写，人物声音不另设清单。
- 待绑定资产只在制作稿保留 `<编号>` 占位并标记“待绑定、不可投产”；确认文字生成的资产写“参考未提供，使用已确认文字资产：<资产名>”，其固定描述只在项目或整集资产区记录一次。任何未解析占位符都不得出现在声称可直接提交的版本中。
- 词头内部可用空行区分风格句、场景行、人物行和道具行，但单个生成段内不得增加第二个锁定标题。整集交付时不得用“同上”“沿用上一段词头”或集中展示一次来替代逐段完整词头。
- 本段动态资产状态必须与词头一一对应，并补充当前位置、姿态、动作、视线、受光、持握、交接、起止和连续性等动态信息；词头遗漏本段实际资产、纳入本段未出现资产或动态状态凭空增加资产，均须先修正。
- 本段无人出镜且没有人物画外连续对白时，省略人物引用与“人物”状态行；存在画外连续对白时保留说话者引用，并在词头和状态中明确“仅画外发声、不入画”及声音承接。
- 本段没有可见、被使用或影响连续性的独立道具时，省略道具引用与“道具”状态行。一次性临时人物、场景或道具只在实际出现的段落直接写必要文字。
- 人物、道具和针对性负向的同类省略自动执行，不再逐段询问导演。

## OUT-03 每段自包含字段

- 每个生成段的制作参考从0.0秒连续核算，并包含段号与总时长、本段动态资产状态、空间与承接、逐镜累计时间、入画／排除范围和段尾快照。
- “空间与承接”写左右、前后、高低、面向、距离、视线轴、摄影机状态和上一段结束快照；首段写初始状态。
- 视频模型复制层在统一词头后使用一个连续的“本段执行约束”，整合人物当前状态、空间与轴线、上一段快照、声音边界、简短通用负向及本段确有的特殊禁项；计划越轴时加入目的、方法、触发、新轴侧和空间重锚。没有额外禁项时不写空占位，也不再拆成多个约束区块。
- 每段镜头卡之后输出“段尾落幅与承接”，包含结束快照和下一段起幅；内容按 [shot-continuity.md](shot-continuity.md) 的 CAM-SNAP 填写，不以泛化“保持连续”代替。

## OUT-04 镜头卡

- 制作参考的镜头映射保留累计起止范围；视频模型复制层每镜以 `【镜头<X>｜时长<X.X>秒】` 开头，只显示单镜时长，并默认使用一个连续段落。按“景别与主体 → 摄影机相对人物／场景的起始位置 → 机位高度 → 观察方向与角度 → 焦距和实际构图范围 → ‘能看到’的初始状态、运镜触发、摄影机路径与沿途画面变化、人物连续动作及结束状态 → 同期或画外连续对白 → 落幅与下一镜承接锚点”书写。固定机位省略不存在的运动过程；复杂运镜的起幅、过程和落幅不得压缩成句末标签。
- 除生成段末镜写“下一段从……承接”外，每镜结尾必须写“落幅于……；下一镜从……承接”，下一镜开头兑现该可见锚点。不得使用“自然承接”“顺势切换”等无法执行的空泛表述。
- 景别字段只写实际景别和主体，不在“全景／中景／近景”等景别前添加“短暂闪回”“回忆”“梦境”或其他叙事标签；这类属性放入制作参考、场景状态或承接说明。
- 使用“能看到……”明确可视内容，并用“先、随后、接着、最后、与此同时”压缩重复主语、保持动作先后。不得为简写改变原有动作顺序、状态变化、口型归属或对白连续性。
- 道具、声音、补充摄影约束、光影和连续性只有在当前镜头存在特异性执行要求时，才在同一段落末尾简短补充；项目要求省略某类描述时直接省略。已经参与画面陈述的运镜须写进动作与构图变化的先后过程，不在句末重复。整集或本段已经锁定的条件不逐镜重复，不保留空栏。
- 不设置“生成语言”“语言音轨”或单独“台词”字段。同期对白与画外连续对白原句只在人物表演中出现一次；音频行不重复台词。
- 每镜“对应原文”只显示在制作参考，不提交视频模型。
- 每张镜头卡主体段落后必须附“入画范围”；“排除范围”在 CAM-FRAME 规定的真实风险触发后必须填写，没有真实风险时省略整行。不得造空栏、填写“无”或复制泛化负向，也不将正向持有状态仅藏在排除范围中。

## OUT-QA 正式稿结构核验

- 正式交付前对最终文本执行结构计数，至少核对：生成段数量与统一词头数量、本段执行约束数量相等；每段都有场景资产行、制作层“本段资产状态”“空间与承接”及“段尾落幅与承接”；镜头卡数量与“入画范围”数量相等；每镜触发的排除风险均有对应“排除范围”；复制层没有未解析占位符。
- 计数只能证明字段存在，不能代替内容审查。还须逐段确认词头资产与本段实际内容一致，逐镜确认入画和排除描述与主体画面、实际位置及连续性没有矛盾。
- 任一必填数量不一致、场景资产行缺失、风险已触发却没有排除范围，均视为正式交付失败并先修正；不得用检查报告中的“通过”覆盖正文缺项。
- 镜头描述不写摄影机或镜头厂商品牌；表演内部不写秒数、毫秒、持续时长或毫米级幅度。硬切作为内部制作规则执行，只有镜头存在特殊声音承接、动作阶段或段尾状态时才在该段末尾补充切点，不写泛化的“全部硬切”。

## OUT-05 分层负向

- 通用层只保留人物／肢体变形、身份漂移、闪烁、乱码、额外人物等高频风险。
- 针对层只写当前段真实风险，例如画外对白口型错配、人物位置互换、道具换手或消失、服装变化、光源漂移、镜面错误、重复脸或肢体粘连。
- 先写清正向状态。不得用负向词禁止原剧情需要的雨、哭泣、拥抱、文字载体或动作，也不堆砌与本段无关的画质口号。

## OUT-06 项目沉淀

- 项目提示词、反馈、状态快照和结论只写入当前本地项目目录。通用规则只有经导演确认后才能更新技能。
- 后续局部更新保持现有资产名、编号、确认状态和已确认长镜头状态；未变化内容不重复询问。
