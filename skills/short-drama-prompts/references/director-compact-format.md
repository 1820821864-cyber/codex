# 导演偏好紧凑提示词格式

本模板用于导演要求的剧集级紧凑排版。剧情、旁白、对白、时长、资产和声音边界仍以主技能为准。默认视觉媒介为真人写实；地域、时代、题材、美术方向、色彩、光影、画幅和镜头气质均按项目填写，不把示例偏好设为通用事实。项目明确采用非真人媒介时覆盖默认。画幅没有全局默认值，必须使用当前项目已确认值；未确认时写“待确认”。

## 排版原则

- 先集中写“镜头风格／场景／人物”三层严格锁定；有关键道具时增加“道具·严格锁定”，有对白时增加“音色·严格锁定”。
- 制作参考与可复制提示词明确隔离。每镜“对应原文”只出现在制作参考，不提交视频模型。
- 可复制区沿用导演喜欢的连续短句：景别、主体、地点、初始状态、触发、连续微动作、结束状态和对白写成一段；摄影机、光影与道具、音频、连续性另起短行。
- 对白原句只在人物表演段落出现一次；不另设“台词”“生成语言”或“语言音轨”，音频行不重复台词。
- 已确认参考音频是人物音色最高依据；文字音色描述只从中提炼并补充场景表演，不得与参考音频冲突。
- 可使用少量情绪词作为表演方向，但必须紧接按先后发生的可见微动作或可听声音变化；不得只写情绪词，不写心理活动、内心独白或不可见意图。
- 默认单镜不超过4秒，但不机械生成等长镜头。超过4秒时必须单独汇报对应原文、使用理由和可拆方案，待导演观看后决定保留。微动作只写先后与状态变化，不在镜头描述内部标秒数、毫秒、持续时长或毫米级幅度；镜头标题仍保留整体起止时间。
- 不使用摄影机、镜头厂商或镜头系列品牌参数；只写景别、机位、角度、焦距、景深和运镜。光圈只在确需进一步约束景深时填写。

## 可复制模板

```text
第<X>集｜生成段<i>/<N>｜总时长<X.X>秒
时长状态：<暂估，待正式音频锁定／正式音频已锁定>

制作参考（不得提交视频模型）
【镜头一（0.0–X.X秒）】对应“<原文旁白或对白>”
【镜头二（X.X–X.X秒）】对应“<原文旁白或对白>”
<依次列全；连续镜头共用一句原文时标明覆盖范围，不复制或改写原句>

视频模型提示词（从此处开始复制）

【镜头风格·严格锁定】
真人写实，<当前项目确认的地域、时代、题材、美术、色彩、光影和镜头气质；非真人项目替换“真人写实”>，画幅：<当前项目确认值／待确认>，<固定／手持／跟拍的使用边界>，<自然剪辑节奏>。默认单镜不超过4秒；长镜头只在内容无法自然拆分时使用并单独汇报。无背景音乐；不朗读、不生成旁白。

【场景·严格锁定】
<严格参考@ImageN或已确认场景资产>。<空间层级与固定布局>。<入口、出口、关键区域及人物可行路径>。<真实光源、方向、色温、反差和阴影>。<不得漂移的材质、陈设和时段状态>。

【人物·严格锁定】
<人物A>：严格参考<@ImageN／已确认资产>。<时期造型、服装、识别特征、初始位置>。全段外观与服装连续。
<人物B>：严格参考<@ImageN／已确认资产>。<时期造型、服装、识别特征、初始位置>。全段外观与服装连续。
<临时人物／群体>：<数量、服装、功能和初始区域>。

【音色·严格锁定】（本段无人物对白时省略）
<主要重复人物>：严格参考当前项目已确认的参考音频<或可用声音映射>并调用固定音色资产；参考音频为最高依据，文字只补充本场表演；保持基础声音身份，当前场景只调整有剧情依据的情绪、音量、语速、停顿和呼吸。
<临时人物>：使用本场次确认音色，不建立跨集锁定。

【道具·严格锁定】（无关键道具时省略）
<道具名>：<外观、初始持有人、持握方向、起止状态和交接关系>。

【空间与承接】
<左右、前后、高低、面向、视线轴、人物距离>。<上一段结束时的人物、动作、道具和光线状态；首段写初始状态>。

【通用负向】
<人物与肢体变形、身份漂移、闪烁、乱码、额外人物等简洁通用风险>。

【本段针对性负向】
<只写本段真实风险，如口型错配、道具换手、位置互换、服装变化、光源漂移；无则写无>。

【镜头一（0.0–X.X秒）】
<景别>·<主体>·<准确地点>·<初始姿态与视线>·<可选少量情绪词：立即接可见微动作或声音变化>·<触发动作或同期对白>·<用“先／随后／说完后”等关系写少量连续微动作，不标内部时间>·<明确结束状态>。倾听者只保留一个清晰反应；画外连续对白须标说话者并保持声音连续。

摄影机：<机位与角度>，<焦距>，<景深>。<固定／从何处跟到何处／单方向运镜的起止和速度>。

光影与道具：<主光来源、方向、人物受光侧、色温>；<道具起止状态>。

音频：<对白声场、环境底声、呼吸、拟音和至多一个核心声音焦点>。无背景音乐；不生成旁白。

连续性与剪辑落点：<继承状态>；<动作、视线、声音或道具的结束画面>；<直接切或有真实依据的转场>。

【镜头二（X.X–X.X秒）】
<按同一结构续写；镜头数量由内容决定>

长镜头报告
<无／镜头X：X.X秒；对应原文：“……”；使用理由：<为何不能在4秒内自然完成>；可拆方案：<拆分机位与自然切点>；确认状态：待导演确认／导演已确认保留>
```

## 定稿检查

逐镜确认：视觉媒介使用真人写实默认或当前项目已确认的替代媒介；地域与美术风格只取当前项目设定；画幅使用当前项目确认值且跨集一致；主要重复人物调用当前项目固定音色且无音色漂移，已确认参考音频优先于文字描述，临时人物使用本场次音色；对应原文没有遗漏或错序；默认单镜不超过4秒；所有长镜头已汇报并记录导演确认状态；情绪词均有紧邻的可见微动作或声音证据；微动作描述无内部时间标注；动作和对白能在镜长内自然完成；人物位置、视线轴、服装、光线和道具从前镜结束状态继续；参考图锁定与文字状态不矛盾；模型区无旁白、无重复对白、无背景音乐。
