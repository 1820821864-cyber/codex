# 轴线法则与高级越轴方法库

本库保存180度法则、合法越轴方法和主动越轴叙事技法。默认禁止无目的、无缓冲的随意越轴；越轴是需要明确设计、承接和复核的空间事件。

## 核心定义与默认红线

### 三类核心轴线

1. **关系轴线／对话轴线**：核心人物之间的假想连线，决定对话、对峙中的左右位置和视线方向。
2. **运动轴线**：人物、车辆、抛掷物或其他主体的主要运动方向，决定动作、追逐和交通镜头中的行进方向。
3. **方向轴线**：单个人物的视线、身体正面或明确目标方向形成的隐性轴线，决定单人镜头的朝向一致性。

### 180度法则

- 默认把摄影机限制在当前主轴同一侧的180度半圆内，使人物朝向、左右位置、视线对接和运动方向保持一致。
- 摄影机越到另一侧会使朝向、左右或运动方向反转；没有叙事目的与空间解释时属于连续性错误。
- 每个对话、动作或群像叙事单元先确定当前主轴、机位所在侧、人物左右关系与允许的运动方向。主轴可随人物真实换位、目标改变或群体行动变化而更新，不得在画外漂移。

### 必须守轴的场景

- 新空间尚未用全景或等效空间基准建立人物站位、空间格局与主轴前，不得越轴。
- 日常双人交流、平稳正反打、生活化叙事和抒情段落默认守轴，确保视线相对。
- 连贯动作、奔跑、格斗、车辆行驶和追逐默认保持运动轴同侧。
- 会议室、餐桌等站位明确的群像场景，以核心关系轴为稳定基准，不因轮流反应频繁换侧。
- 无叙事目的、无可见动作、无中性缓冲、无连续机位运动、无空间重建的越轴一律修正。

## 合法越轴方法

合法越轴须先明确目的，再让观众看见或理解方向变化的理由。正式设计记录旧轴侧、新轴侧、触发点、所用方法、硬切锚点与重建立镜头。

### 骑轴中性镜头

- 在轴线正上方建立正面或背面中性构图，弱化左右朝向，再硬切到另一轴侧。
- 中性镜头必须有原文、对白或动作承载，不能只为技术过轴增加无信息镜头。

### 动作支点越轴

- 在转身、转头、起身、换位、挥臂或物体经过前景等改变朝向或遮挡关系的动作峰值硬切。
- 下一镜从同一动作方向、同一阶段或紧接阶段起幅，不让人物复位重做。
- 遮挡只是匹配点，不生成连续遮挡转场。

### 摄影机连续运动越轴

- 通过横移、环绕或跟拍，让摄影机在同一连续镜头中从轴线一侧移动到另一侧；观众必须看见跨越过程和关系变化。
- 写清起幅轴侧、靠近骑轴、实际跨轴、背景视差变化与新轴侧落幅。超过默认镜长时按长镜头规则处理。

### 特写或空镜缓冲越轴

- 越轴前插入1–2个无明确左右方向的脸部、物件或环境细节镜头，暂时弱化原轴，再硬切到另一侧。
- 缓冲镜头必须由现有旁白、对白或画外连续对白承载并提供新信息；越轴后仍须在1–2镜内重建空间。

### 全景重建立越轴

- 人物大范围调度或空间结构变化需要换侧时，越轴后用全景重新交代人物站位、参照物、行动方向和新关系轴。
- 全景必须让观众确认左右关系，不只是展示环境。

### 人物真实换位越轴

- 人物在画面中真实交换左右位置后，摄影机切换轴侧是对新关系的还原。前镜必须让观众看见换位过程或关键阶段，下一镜继承结果。

### 渐变式多步越轴

- 用3–4个有效镜头逐步接近骑轴位置再进入另一侧；各镜通过共同主体、动作、视线或构图重心承接。
- 每一步必须新增叙事信息，不能为了隐藏越轴堆积无效机位。也可在一个连续运镜内完成。

## 分场景规则

### 双人对话与对峙

- 常规交流守关系轴，正反打保持同侧和准确视线对接。
- 权力发生反转时，可由人物起身、换位、靠近、退开或摄影机连续运动完成越轴，使空间关系对应权力变化。
- 冷战、分手或沟通失效可主动破坏精准视线对接，但必须明确这是叙事表达而非误设机位。

### 动作、追逐与格斗

- 追逐以整体运动方向为主轴。人物转弯、掉头或目标真实改变时，借动作支点或全景重建立换轴。
- 近身缠斗和换位可多次用动作支点改变轴侧，但每次保留敌我位置、受力方向和动作阶段。
- 爆炸、撞击、惊吓或动作高潮可用景别跨级加主动越轴制造冲击，但须在随后1–2镜内重新锚定空间。

### 多人群像

- 存在核心对话时，以核心人物关系轴为主；次要人物可形成局部方向轴，但不破坏核心左右关系。
- 环形站位可用连续环绕自然跨轴，也可用中间人物的中性镜头分步切换。
- 群像整体移动时，以群体主要运动方向为运动轴；个体短暂偏离不自动构成越轴。

### 心理、回忆与虚幻

- 精神崩溃、认知颠覆或世界观崩塌时，可用主动越轴让空间错位对应心理失序；轴线变化必须落在明确情绪触发点。
- 回忆、幻觉、梦境和平行时空可用方向差异标识非现实属性；进入和离开时写清触发、边界与现实空间重建。

## 主动越轴的叙事用途

主动越轴必须表达内容，不能同时假装它没有发生：

1. **疏离与荒诞**：破坏视线逻辑，表现沟通失效或人物异化。
2. **权力关系反转**：随话语权转移改变画面侧别。
3. **跳轴冲击**：反转、惊吓或高潮时把景别落差与方位错位结合，随后重建空间。
4. **沟通错位**：用左右关系变化表现心理裂痕。
5. **现实与虚幻区分**：现实守轴，非现实段主动换轴。
6. **心理失序**：让越轴与倾斜构图、手持或景别割裂协同。

## 越轴红线与创作分寸

1. 观众尚未建立当前可知空间与主体方向前不得越轴。
2. 日常叙事和平缓情绪尽量不用主动越轴。
3. 每次越轴必须有明确叙事或情绪目的；仅为展示机位或追求高级感的越轴属于失败。
4. 越轴后须在1–2镜内用全景、固定参照物、真实换位结果或连续摄影机路径重新锚定空间。
5. 同一场景内无特殊目的的越轴不宜超过一次；再次越轴必须对应新的重大变化并重新检查目的与锚定。
6. 主动无缓冲越轴只用于明确的心理崩塌、权力颠覆、惊吓、高潮、沟通失效、现实／虚幻区分或荒诞疏离。

## 逐镜设计与检查

- 列镜头前建立轴线记录：当前主轴类型、轴线两端、摄影机所在侧、人物左右／视线／运动方向，以及轴线何时因真实动作变化。
- 每镜起幅继承前镜轴侧与方向；落幅记录机位侧别、人物朝向、视线、运动方向和下一镜承接锚点。
- 计划越轴时，在制作参考或本段执行约束写明“越轴目的 → 越轴方法 → 触发动作或中性缓冲 → 新轴侧 → 1–2镜内空间重锚”。
- 未计划越轴时保持当前主轴同侧；焦距、景别和高度变化不等于换轴。
- 定稿时连续审查人物左右、视线、运动和受力方向。未标注的方向反转按意外越轴处理并修正。
