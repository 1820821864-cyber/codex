# 景别切换与氛围方法库

本库提供景别、场景调度、氛围和声画组织方法。它不改变原文、音频、时长、资产、剪辑和输出规则；从中选择能强化当前叙事重点的方法，不为展示技巧堆叠全部手段。

## 执行解释

- 景别层级按“大远景／大全景 → 远景／全景 → 中景 → 中近景／近景 → 特写 → 大特写／微距”理解；同层微调不算跳级。
- 固定级数、镜头循环和节奏数值只作创作标尺；实际执行服从语言、动作、信息和生成条件，超过默认镜长仍进入长镜头报告。
- “匹配转场、穿档切、景别转场”统一转译为硬切或项目已确认的剪辑方式：前镜内部建立遮挡、动作、构图或声音锚点，下一镜从该锚点起幅，不生成无依据的连续变形。
- 空镜、物件镜头和无人物画面须能反查到原文或经授权故事稿，并提供新信息、状态变化或情绪结果；它们可以是有依据的静默节拍，但不能只靠环境音取得切镜资格。
- 光影只使用已建立的真实光源，变化须有时间、天气、开关灯、人物移动或环境变化依据；声音只使用当前项目允许且有剧情依据的声源。

## 通用顶层法则

### 景别跳级与情绪量级

- 跨1级用于注意力集中、小幅情绪升级或关键反应落定。
- 跨2级用于强戏剧冲击、权力骤变、真相揭露或认知翻转。
- 跨3级保留给单集或全片最强高潮，且须先建立可识别的空间与主体。
- 特写反向跳到全景或远景，可表现疏离、关系割裂、人物被环境吞没或视点抽离。
- 跳级跨度须对应情绪、信息与关系变化强度；无目的跨级须修正。

### 景运耦合

- 景别收紧时可用前推、人物靠近或构图压缩；景别拉开时可用后撤、人物离开前景或重新纳入环境。
- 运镜速度与情绪、语速和景别变化共同组织。快速切换前让前镜运动在清楚落点收束，不能在动作含混处强停。
- 固定机位、人物调度或硬切更能表达原文时，不机械使用推拉。

### 视觉重量平衡

- 相邻镜头检查主体占比、明暗分布、色彩密度和构图重心，使普通承接保持视觉重量连续。
- 压迫、失衡、疏离或反转需要不平衡时，把它作为有动机的关系变化，并由下一镜接住。

### 景别呼吸

- 场景长度允许时，可形成“建立关系 → 收紧到情绪或信息落点 → 适度释放”的呼吸。
- 情绪持续压迫、突然爆发或刻意屏息时可延迟、打断或冻结呼吸；不得为完成形式新增镜头或改写原文。

### 氛围底层逻辑

- 景别控制心理距离，光影定义项目允许的情绪基调，构图强化关系张力；三者服务同一叙事重点。
- 光影和色彩不随景别无依据变化；构图不能为氛围破坏人物位置、口型、道具和空间连续。

## 场景化景别组织

### 双人对话与对峙

- 关系对等时双方初始景别相近；权力变化后，景别、主体占比和运动状态随关系改变。
- 告白、谈判升级和真相揭露可同步收紧双方景别；顶点用短促可辨认的手部、呼吸或视线细节落定。
- 训话、审讯可让强势方逐步收紧，弱势方保持或拉开；一动一静须对应已发生的权力变化。
- 冷战、分手可使用一近一中、错位反打或留白表现隔阂，但仍服从真实轴线。
- 长段生活化对话可用横移、侧移、半环绕或焦点转移交接双方；超过默认镜长须报告。

### 多人群像

- 用全景建立空间和站位，中景区分核心对话区与旁观区，近景／特写聚焦说话者、执行者或关键反应者。
- 环移经过核心人物时可收紧，经过边缘层时拉开；每次层级改变都须新增信息。
- 可在同一构图中用焦点转移改变注意力归属，避免无意义逐人切镜。

### 动作、追逐与格斗

- 远景／全景交代格局，中景显示完整肢体动作，特写确认打击点、受力和关键道具。
- 运动匹配切换保持运动方向、受力方向和动作阶段连续，不让动作复位。
- 动作高潮可加大景别跨度和有效切换频率，但必须保持空间和动作可读。
- 跟拍长镜头通过摄影机移动和人物调度改变景别；路径、目标与落幅须清楚。

### 心理独角戏

- 用中景建立处境，近景聚焦，特写确认触发或生理证据，再回到较大景别表现抽离、稳定或结果。
- 心理割裂可采用不规则但有切镜资格的特写；每次切换都要产生新信息。
- 有原文承载的既有物件可作为情绪锚点，不能把通用意象凭空加入剧情。

### 悬疑、惊悚与恐怖

- 先选择信息差：观众全知时可先展示危险；观众未知时只给人物反应；人物全知时保留其已知信息边界。
- 可使用“线索特写 → 人物反应 → 拉开揭示全貌”的延迟揭示。
- 二次冲击必须带来新威胁或新认知，不能重复同一惊吓信息。
- 反派可用远景、背影、虚焦或局部细节控制信息，但不得泄露尚未揭示的身份。

### 大场面

- 用宏观—中观—微观三级嵌套：大景别建立规模，中景展示群体行动，近景／特写落到个体命运。
- 高位到人物的连续路径每一级都须新增尺度或事件信息。
- 多线并行时可随高潮同步收紧，并在共同事件点汇聚到同量级落点。

### 时空切换

- 可用同量级景别、同构图重心、同类主体、动作或声音锚点完成硬切。
- 从极小景别切到极大景别可表达明确的大跨度时间或空间变化。
- 前镜特写包含下一场景既有元素时，可在该元素落幅，下一镜用对应构图起幅；不生成变形穿越。

### 感情戏

- 景别远近表现心理距离，运镜轨迹表现靠近、迟疑或抽离，正反打对称度表现关系是否对等。
- 暧昧试探保留社交距离，关键对视或接触才短时收紧。
- 告白可由中景推进至近景或特写，视线由回避转为直视，双方景别逐渐对等。
- 争吵可由双人中景分裂为单人近景，随冲突升级加快有效切换；骤停须有动作落幅。
- 决裂可从特写拉到中景或全景，用视线错开、取消同框、人物离画或空位结果表现关系割裂。

## 标志性方法族

- **透视推拉**：摄影机前推同时反向变焦，尽量保持主体大小稳定，让背景透视变化；用于眩晕、不安或世界崩塌，并写清推轨、变焦方向和背景纵深。
- **对称固定与极慢切换**：使用有空间基础的对称构图、固定机位和克制切换制造审视、冰冷或宿命感；不把对称强加给非对称场景。
- **碎片化景别跳切**：近景／特写碎片与较大景别并置，用于时间朦胧或情绪破碎；每个碎片仍须有叙事承载、新信息和承接。
- **光影匹配**：以前后镜真实光向、明暗分布和色温关系作为切换锚点，不无触发改灯。
- **生活流留白**：固定中景、全景、平缓切换和生活化表演承载细腻情绪；留白仍须有剧情状态或结果。

这些名称只描述方法，不要求模仿特定作者或作品；最终方案按当前项目重构。

## 景别禁忌

1. 不做无情绪、信息或关系依据的跨级跳切。
2. 不做无权力或关系变化支撑的正反打景别失衡。
3. 新空间未建立前不以特写导致方位丢失；有意隐藏空间时明确受限信息策略。
4. 景别节奏不得与情绪错位。
5. 特写须保留景别对比和明确的信息落点，不能滥用。
6. 氛围、光影、色彩和构图不得与当前关系、真实光源或连续性矛盾。

## 氛围进阶方法

1. **景光一体调度**：人物或摄影机在既有光区间移动，使景别变化与真实受光变化共同发生，不生成无触发调光。
2. **空镜情绪锚点**：用大景别定调或物件特写承载状态结果；仅在有叙事承载时使用，不当作通用转场。
3. **呼吸感剪辑**：平静段可适当舒展，紧张段可短促，极致情绪可用经确认的长镜头；最终镜长仍按音频、表演、动作和工具条件核算。
4. **前景层次**：优先使用真实且具有关系意义的前景；不存在有效前景或会遮挡关键信息时省略。
5. **声画景别对位**：全景优先有剧情用途的空间声源，中景突出对白与动作，特写突出可确认的呼吸、布料或接触细节；不自动新增环境底声、心跳或音乐。
