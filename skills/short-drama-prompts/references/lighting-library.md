# AI短剧光影与色彩库

本库用于建立场景固定光影、选择有剧情依据的风格方案，并保持跨镜与跨生成段连续。先锁定物理光源，再决定视觉风格；调色不能代替布光，也不能制造剧本没有的情绪。

## 场景光影锁定字段

每个场景资产至少记录：

```text
时段与天气：<室内/室外，具体时段，天气>
实景光源：<窗、太阳、顶灯、台灯、路灯、屏幕等及其位置>
主光：<来源、画面方向、人物受光侧、硬/软、色温>
辅光：<来源、方向、强弱或与主光的反差关系>
轮廓/背景光：<有则写真实来源；无则写无>
阴影：<方向、边缘软硬、密度>
曝光：<正常、高调、低调；高光与暗部保留要求>
基础色彩：<主色、中性色、点缀色、肤色要求>
连续性锁定：<不可随镜改变的光源、方向、色温与影子>
允许变化：<剧情触发条件及变化后的状态>
```

## 稳定性原则

- 高：单一主光方向明确、色温关系简单，适合直接生成。
- 中：混合色温、逆光、低照度或可见光束，需要减少人物、动作和背景复杂度。
- 低：灯光闪烁、快速明暗变化、多色动态霓虹、运动中连续换光；优先拆镜或后期完成。
- 人物肤色、服装固有色和关键道具颜色优先保持准确，不被调色吞没。
- 连续对白场景优先稳定面部曝光，不让强逆光、频闪或彩色光破坏口型与身份一致性。

## 基础光型

| 光型 | 真实光源与用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 自然日光 | 窗外天空、太阳；日常、客观叙事 | 高 | 写清窗户方向和太阳侧，跨镜不跳边 |
| 阴天漫射光 | 云层形成大面积柔光；克制、现实感 | 高 | 阴影柔和但不能完全无方向 |
| 金色时刻 | 低角度夕阳/晨光；原文明确的清晨或黄昏 | 中 | 时段必须成立，连续场景色温不漂移 |
| 蓝调时刻 | 日落后天空冷光配室内暖灯 | 中 | 锁定冷外暖内关系，不逐镜互换 |
| 高调柔光 | 大面积窗光、柔化灯或白墙反射；明亮、轻松 | 高 | 保留面部层次，不做无阴影塑料感 |
| 低调高反差 | 单侧窗光、台灯或窄束灯；悬念、隐藏信息 | 中 | 暗部仍需保留人物识别和关键动作 |
| 伦勃朗式侧光 | 单侧较高主光；明确的矛盾或内敛张力 | 中 | 必须有对应窗/灯，不机械套在普通对白 |
| 顶光 | 吊灯、路灯、天井；压迫、审讯或空间真实感 | 中 | 防止眼窝全黑；必要时有合理弱辅光 |
| 底光 | 地灯、火焰、屏幕下方光源；异常或局部惊悚 | 中 | 仅有真实低位光源时使用，时长从短 |

## 逆光、轮廓与体积光

| 光型 | 剧情用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 逆光 | 入场、分离、身份暂不清晰或明亮背景 | 中 | 写明背后光源；需要看脸时补合理正面反射 |
| 剪影 | 暂时隐藏身份、强调动作轮廓 | 高 | 不用于需要口型、表情或人物识别的镜头 |
| 轮廓光 Rim Light | 从背景分离人物、夜景边缘勾勒 | 中 | 必须来自后方窗、灯或太阳，不凭空发光 |
| 丁达尔/体积光 | 有雾、尘、水汽环境中的可见光束 | 中 | 同时写明介质和窄束光源；普通干净室内不用 |
| 门缝/窗缝光 | 揭示、窥视、空间阻隔 | 高 | 光束形状服从真实开口，位置跨镜一致 |

## 实景光与混合色温

| 方案 | 真实来源 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 暖色台灯/吊灯 | 钨丝灯、暖色LED | 高 | 暖光范围与灯具位置一致 |
| 冷色办公顶灯 | 荧光灯、冷色LED | 高 | 避免无依据频闪；肤色适度保留 |
| 屏幕光 | 手机、电脑、电视 | 中 | 只影响靠近屏幕的面部区域，亮度不过曝 |
| 路灯与车灯 | 夜间道路真实灯具 | 中 | 明确光线方向和车辆运动路径 |
| 冷外暖内 | 窗外夜/阴天冷光＋室内暖灯 | 中 | 作为固定空间关系，不逐镜翻转 |
| 暖外冷内 | 夕阳/街灯暖光＋室内冷灯 | 中 | 必须符合时段和灯具类型 |
| 霓虹混合光 | 店招、街区霓虹 | 低 | 固定两种以内主色，禁止快速多色闪烁 |
| 烛火/火焰 | 可见火焰 | 中 | 轻微自然波动即可，不让人物脸持续变形 |

## 色彩方案

色彩方案应基于场景材质、服装和真实光源。以下为可调用方案，不是固定情绪公式。

| 方案 | 适用条件 | 稳定性 | 限制 |
|---|---|---:|---|
| 中性自然色 | 日常、客观叙事、人物资产确认 | 高 | 默认方案，肤色真实 |
| 暖色主导 | 暖灯、夕阳或暖色空间确实存在 | 高 | 不把所有肤色染成橙色 |
| 冷色主导 | 阴天、夜景、冷色灯具或剧情空间成立 | 高 | 保留皮肤与关键道具可辨识度 |
| 青橙分离 | 冷背景与暖肤色/暖实景灯同时存在 | 中 | 适度使用，不作为默认“电影感”滤镜 |
| 低饱和 | 原剧情明确的疲惫、现实或回忆质感 | 高 | 不能改变已锁定服装、道具识别色 |
| 高饱和点色 | 关键物件或场景本身具有鲜明色彩 | 中 | 主色不超过两到三种，避免全画面发艳 |
| 单色倾向 | 梦境、监控或明确风格段落 | 中 | 必须与常规现实段落有剧情边界 |

## 剧情动机与光线选择

- 权力变化：优先通过人物位置、构图和合理侧光表达；不要突然把普通室内变成戏剧性顶光。
- 信息隐藏/揭示：可用遮挡、逆光、灯具开关或人物走入既有光区，必须有可见触发。
- 关系拉近：可调整构图与景深；除非人物移动靠近真实暖光源，不应无故整体变暖。
- 恐惧/失控：可在真实低照度、闪烁灯具或移动光源下表达；不凭空添加频闪。
- 回忆/梦境：只有剧本明确进入非现实时才使用柔焦、低饱和或单色倾向，并设置清晰进出边界。

## 光线变化协议

连续场景只允许以下变化：

- 时间确实推进，太阳高度或环境亮度发生合理变化。
- 天气变化在剧本或可见画面中发生。
- 人物开关灯、拉帘、开门或移动屏幕等动作改变光源。
- 人物从既有光区移动到另一光区。
- 车辆、路灯或其他移动实景光源经过。

每次变化写明：触发动作、变化开始点、受影响区域、新旧色温/方向关系，以及下一镜继承状态。没有触发就保持场景资产中的基础光影不变。

## 提示词调用格式

```text
光影方案：<库中方案或组合>
物理光源：<来源、位置、方向>
剧情动机：<为什么本镜需要该光影>
人物受光：<主受光侧、眼神光、肤色与曝光>
背景与阴影：<色温、反差、影子方向与软硬>
连续性：<继承的固定状态或本镜可见触发的变化>
稳定性/限制：<高/中/低及简化或替代方案>
```

## 常见失败与修正

- 光源漂移：同一窗或灯在相邻镜改变方向。修正为复述固定方位和人物受光侧。
- 无源轮廓光：人物边缘发亮但背景没有灯。修正为增加可见合理光源或删除轮廓光。
- 肤色跳变：调色随景别变化。修正为锁定肤色与白平衡，仅改变景深和构图。
- 影子跳轴：人物位置未变但影子方向反转。修正为锁定主光方向和机位轴线。
- 强光吞细节：逆光或暗调导致口型、眼神、道具不可见。修正为降低反差或加入真实反射辅光。
- 动态彩光变形：多色频闪导致脸和服装漂移。修正为固定两种以内颜色，或把变化交给后期。
