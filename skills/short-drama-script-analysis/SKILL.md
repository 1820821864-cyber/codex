# 短剧剧本与人物分析

每次开始相关任务都重新读取本技能、当前剧本、当前项目目录中的项目记忆、已有诊断和任务依赖的交付文件。即使这些结论刚在对话中出现，也以当前项目文件的最新版本为准；上下文压缩、长时间中断或切换项目后再读一次。每个项目完全隔离：禁止搜索、读取、继承、比较或复用其他项目的剧本、人物、资产、提示词、偏好与结论；只有用户明确点名某个项目作为参考时才可跨项目读取。项目数据不得写入技能仓库或云端。

## 输出

1. 用一句话给出主题、视觉基调和情绪曲线。
2. 诊断题材与受众、前三秒钩子、每 5–10 秒信息点、情绪曲线、集末悬念、角色弧光和台词长度。
3. 建立人物卡：定位、外貌、气质、动机、造型、30–60 字 canonical 描述词、表演要点、关系、确认状态。
4. 修改建议只优化呈现、节奏与镜头表达。除非用户明确要求改写，否则不改台词、情节、设定和时间线。

## 本地项目写入

- 在项目根目录创建或更新项目记忆、人物档案与制作结论；未经确认的外观标记“待确认”。
- 项目剧本、人物、资产、提示词、偏好、结论和媒体只保存在该本地项目目录，禁止提交到技能仓库。
- 如果用户纠正会改变可复用技能规则，先说明拟更新内容并询问是否更新技能；用户明确要求更新时无需重复询问。只有确认后的通用技能变更才同步云端。
