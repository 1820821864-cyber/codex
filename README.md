# Codex Short Drama Director 3.3

面向 Codex 的模块化短剧工作流技能仓库。云端只保存可复用技能；剧本、人物、资产、提示词、反馈、结论和媒体始终留在各自的本地项目目录。

## 技能结构

- `short-drama-director`：中心路由；按任务调用次级技能，不承载阶段细则。
- `short-drama-script-analysis`：剧本诊断、人物关系、节奏和项目建档。
- `short-drama-story-writing`：在保护原剧情与对白的前提下，将剧本完善为可视化、可表演的故事稿。
- `short-drama-assets`：人物、场景、道具和参考音频资产。
- `short-drama-prompts`：视频提示词中心；按需加载内部规则模块、模板、适配器和库。
- `short-drama-image-design`：剧情图、宣传海报、角色视觉、参考图生成和图像编辑方案。

提示词技能的内部结构：

```text
references/
├─ modules/       剧情、音频、资产、表演、镜头连续性、时长、风格、输出
├─ templates/     导演偏好紧凑排版
├─ adapters/      Seedance／即梦等工具特有差异
├─ libraries/     摄影机、轴线、景别氛围、光影、仪式与特效选项
├─ quality/       正式交付检查
└─ maintenance/   规则唯一归属与更新索引
```

普通局部任务先读取规则索引并补齐必需依赖；正式单集读取全部必要模块并执行完整检查。中心技能通过当前状态入口与执行清单记录有效文件、实际调用技能、模块依赖和冲突处理。每条规则只有一个权威文件，模板和检查表不重复规则正文。

## 3.3 核心工作方式

- 项目完全隔离，执行前重读当前项目资料。
- 严格保持原剧情；按剧本格式区分对白、明确旁白、动作／场景说明和制作元数据，旁白逐句配画面。
- 每镜都能反查到原文或授权故事稿；有依据的静默动作、空间建立和反应可以成镜，无来源空镜不得填时长。旁白不进入视频模型，人物对白由画面生成且不与旁白重叠。
- 未指定工具或使用 Seedance／即梦时，单次生成4–30秒、每段最多9镜、默认单镜不超过4秒；其他工具由适配器提供边界。
- 项目未确认其他方案时默认硬切且无背景音乐；导演确认的剪辑与音乐方案写入项目状态并保持一致。
- 外观参考图和声音参考音频分别是对应身份的最高依据；不使用文字音色描述。
- 人物资产不输出 `canonical`；正式交付保留完整检查报告。

3.3在3.2基线上增加：当前状态入口与执行清单、运行期依赖闭包、轴线与越轴方法库、景别与氛围方法库、逐镜四层审查、参考资产三态、创意母版／投产方案，以及制作参考层／视频模型复制层分离。原有入画边界、姿态、道具交接、场景实体复用、身体形态状态和制图分支继续保留。

## 版本、归档与同步

- `初版`：2.0精简重构前的完整快照。
- `v2.0-final`：2.0最终归档，精确指向 `v2.0.33`。
- 当前维护版本：`3.3.3`。
- `scripts/validate.ps1`：验证技能、版本、相对链接和模块路由。
- `scripts/install.ps1`：把仓库技能安全安装到本地 Codex 技能目录并复核。
- `scripts/sync.ps1`：验证、白名单与隐私审计后提交，在推送前安装并复核本地技能；仅允许指定 `origin`，可发布与 `VERSION` 一致的不可移动版本标签，普通推送且不强推。

发布新版本示例：

```powershell
pwsh -File scripts/sync.ps1 push -Message "release: update skills to 3.3.3" -Tag v3.3.3
```
