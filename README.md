# Codex Short Drama Director 2.0

面向 Codex 的短剧工作流技能仓库。云端只保存可复用技能；剧本、人物、资产、提示词、反馈和媒体始终留在各自的本地项目目录。

## 技能

- `short-drama-script-analysis`：剧本诊断、人物关系和项目建档
- `short-drama-assets`：人物、场景、道具和音频资产
- `short-drama-prompts`：分镜与 AI 视频提示词

提示词技能按需读取以下参考：

- `references/seedance.md`：Seedance／即梦生成格式
- `references/director-compact-format.md`：导演偏好的严格锁定与紧凑镜头模板
- `references/shot-library.md`：镜头语言、稳定性与替代方案
- `references/lighting-library.md`：光影、色彩与连续性
- `references/delivery-checklist.md`：正式交付检查

## 2.0 核心约定

- 项目完全隔离；执行任务前重读当前项目资料。
- 严格保持原剧情。人物对白以外的原文均为旁白，逐句配画面。
- 分镜规划中每镜必须由旁白、同期对白或画外连续对白承载，不制作无叙事承载的空镜。
- 人物对白由视频模型在画面中生成；旁白只作制作参考并在后期合成，不进入视频模型提示词，两者不得重叠。
- 单次视频生成4–30秒，按内容拆段，不机械套用固定镜长。
- 全片无背景音乐。
- 人物资产不输出 `canonical` 字段；使用已确认事实、时期造型、识别特征和参考图。
- 正式交付附可见检查报告。

详细执行规则只维护在相应技能中，README不再重复展开。
