# Codex Short Drama Director 3.0

面向 Codex 的模块化短剧工作流技能仓库。云端只保存可复用技能；剧本、人物、资产、提示词、反馈、结论和媒体始终留在各自的本地项目目录。

## 技能结构

- `short-drama-director`：中心路由；按任务调用次级技能，不承载阶段细则。
- `short-drama-script-analysis`：剧本诊断、人物关系、节奏和项目建档。
- `short-drama-assets`：人物、场景、道具和参考音频资产。
- `short-drama-prompts`：视频提示词中心；按需加载内部规则模块、模板、适配器和库。

提示词技能的内部结构：

```text
references/
├─ modules/       剧情、音频、资产、表演、镜头连续性、时长、风格、输出
├─ templates/     导演偏好紧凑排版
├─ adapters/      Seedance／即梦等工具特有差异
├─ libraries/     摄影机、光影、仪式与特效选项
├─ quality/       正式交付检查
└─ maintenance/   规则唯一归属与更新索引
```

普通局部任务只读取相关模块；正式单集读取全部必要模块并执行完整检查。每条规则只有一个权威文件，模板和检查表不再重复规则正文。

## 3.0 保持不变的核心功能

- 项目完全隔离，执行前重读当前项目资料。
- 严格保持原剧情；人物对白以外的原文均为旁白并逐句配画面。
- 每镜由旁白、同期对白或画外连续对白承载；旁白不进入视频模型，人物对白由画面生成且不与旁白重叠。
- 单次生成4–30秒；默认单镜不超过4秒，长镜头由导演确认。
- 画面全部硬切；全片无背景音乐；环境声只在确有用途时保留。
- 外观参考图和声音参考音频分别是对应身份的最高依据；不使用文字音色描述。
- 人物资产不输出 `canonical`；正式交付保留完整检查报告。

3.0新增但不改写原有功能的四项稳定性规则：三视图与摄影机观察角度匹配；摄影机驱动的透视、视差和遮挡；生成段首尾状态快照；明显动作的准备、发力、惯性跟随与收势。

## 版本、归档与同步

- `初版`：2.0精简重构前的完整快照。
- `v2.0-final`：2.0最终归档，精确指向 `v2.0.33`。
- 当前维护版本：`3.0.0`。
- `scripts/validate.ps1`：验证技能、版本、相对链接和模块路由。
- `scripts/install.ps1`：把仓库技能安全安装到本地 Codex 技能目录并复核。
- `scripts/sync.ps1`：先验证并安装本地技能，再按严格白名单和隐私扫描提交；可发布与 `VERSION` 一致的不可移动版本标签，普通推送且不强推。

发布新版本示例：

```powershell
pwsh -File scripts/sync.ps1 push -Message "refactor: release modular 3.0" -Tag v3.0.0
```
